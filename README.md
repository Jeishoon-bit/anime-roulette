## 💖 Sobre el proyecto

**AniRuleta** es una aplicación web estática en modo oscuro creada con mucho cariño para ayudarte a descubrir tu próxima serie favorita sin perder horas navegando catálogos infinitos.  

Elige tu género favorito (¡incluyendo **Romance** 💕!), filtra por puntuación mínima, gira la ruleta SVG animada y guarda automáticamente en tu navegador los animes que ya viste para no repetir nunca una recomendación.

> 🛡️ **100% Seguro (SFW):** Todas las consultas bloquean automáticamente contenido adulto, explícito, *Ecchi* y *Hentai* tanto en el servidor como en el cliente.

---

## ✨ Características adorables

- 🎡 **Ruleta SVG animada:** Giro fluido con desaceleración suave y compatibilidad con `prefers-reduced-motion`.
- 🎭 **9 categorías listas para girar:** Acción, Aventura, Comedia, Fantasía, Misterio, Slice of Life, Ciencia Ficción, **Romance** y Sorpresa.
- ⭐ **Filtro de calidad:** Elige desde *Cualquier puntuación* hasta *+8.5 Obra maestra*.
- 🌸 **Datos reales al instante:** Conectado a **AniList GraphQL API** (con enlaces directos a **MyAnimeList**) y respaldo automático con **Kitsu API**, sin necesitar API Keys ni servidores.
- 📝 **Ficha completa del anime:** Portada en alta calidad, título en inglés/romaji y japonés, puntuación, episodios, estado de emisión, etiquetas de género y sinopsis expandible.
- 💾 **Memoria local ("Ya lo vi"):** Guarda tus series vistas en `localStorage` para excluirlas de futuros giros y reinicia el historial cuando quieras con confirmación segura.
- 🌙 **Modo oscuro elegante:** Diseño responsivo pensado para verse precioso tanto en escritorio como en tu teléfono.
